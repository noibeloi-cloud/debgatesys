New attendee

Unique code · letters A–Z, digits, hyphen, period or space · max 16 characters · case-insensitive (Code 39 cards cannot encode anything else)
Type any group name · suggestions come from existing attendees

Import attendees

Header row optional — columns are auto-matched by the words code/card/id, name, group. Without a header the order is code,name,group (or just a name per line). Missing codes are auto-assigned. Duplicate and invalid codes (Code 39 only: A–Z, 0–9, - . space, max 16) are skipped.

Time limits

CHECK-IN WINDOW

Scans outside the window are refused with a red screen. Check-outs are always accepted.

AUTO CHECK-OUT

Closing time: anyone still IN is checked out at exactly that time, and it is also the last moment anyone can check in that day.
Max session: a session is closed once it reaches that length (recorded as exactly that long).
If both are set, whichever comes first applies. Auto check-outs are tagged AUTO. Sessions still open after midnight are always closed at the end of their day (12 h cap).

Reset options

Clear today's sessions

Remove all check-in/out records from today. People and historical data stay intact.

Clear all sessions

Wipe all attendance history across all days. People register is preserved.

Empty system

Delete everything: all people, all sessions, all history. Starts completely blank — no demo data.

Full reset (demo data)

Delete everything and return to the demo seed data.

Tip: export a backup before resetting. Backups can restore any of these states.
